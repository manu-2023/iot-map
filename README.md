
### 1️⃣ Clone the Repository

```powershell
git clone https://github.com/manu-2023/iot-map
cd iot-map
```

### 2️⃣ Frontend Setup (React App)

```powershell
cd frontend
npm install
```

Start the frontend development server:

```powershell
npm start
```


### 4️⃣Backend Setup (Node.js Bridge)

```powershell
cd ../backend
npm install
```
### ▶️ Run the Backend

```powershell
node server.js
```
